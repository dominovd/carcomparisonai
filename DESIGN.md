# Дизайн проекта carcomparisonai.com

## Архитектура

Стек: Astro 5 (статическая генерация + React-острова для интерактива; страницы произвольных пар `/compare/[slug]` рендерятся на сервере через адаптер Vercel) + Tailwind CSS + TypeScript. Хостинг - Vercel, деплой по git push. Данные на старте лежат в репозитории (`data/vehicles.json`) - без базы данных. Это осознанно: статичные страницы собираются на билде, грузятся мгновенно и идеальны для SEO. База (Supabase) появится в фазе 2, когда моделей станет сотни.

Поток данных: FuelEconomy.gov / NHTSA → `scripts/fetch-data.mjs` → `data/vehicles.json` → билд → статичные страницы `/compare/[slug]`.

Структура:

```
app/
  layout.tsx            - шапка, подвал, метаданные по умолчанию
  page.tsx              - главная: hero + сетка сравнений
  compare/[slug]/page.tsx - страница сравнения (SSG, generateStaticParams)
  sitemap.ts, robots.ts - SEO
lib/vehicles.ts         - типы, данные, TCO-калькулятор, вердикты
data/vehicles.json      - данные моделей (seed, обновляется скриптом)
scripts/fetch-data.mjs  - подтяжка свежих MPG из FuelEconomy.gov
```

## Дизайн-система

Шрифт: Inter / system-ui. Тон: чисто, плоско, много воздуха - данные главнее декора.

Цвета:

| Токен | Значение | Использование |
|---|---|---|
| `brand` | #1D9E75 | Акцент, ссылки, CTA, бары TCO |
| `brand-dark` | #0F6E56 | Текст на светло-зелёном |
| `brand-light` | #E1F5EE | Фон вердикта, бейджи «better» |
| `ink` | #0F172A | Основной текст |
| `ink-soft` | #475569 | Вторичный текст |
| `ink-faint` | #94A3B8 | Подписи, сноски |

Компоненты страницы сравнения (сверху вниз): hero с названием пары → карточка вердикта (зелёный фон) → таблица спеков с бейджами «better» у победителя строки → блок TCO с горизонтальными барами и разбивкой → перелинковка на другие сравнения.

Принципы: одна страница = один интент («X vs Y»); вердикт всегда выше таблицы (ответ сразу, детали ниже); каждая цифра со ссылкой на источник в подвале; никаких каруселей и модалок.
